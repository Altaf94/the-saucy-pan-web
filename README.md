# The Saucy Pan: Website

The ordering website for **The Saucy Pan**, an Italian pasta brand, built with Next.js (App Router) and TypeScript.

**Live:** https://startup-orpin-eight.vercel.app

## Features

- Menu grid, category cards and featured dishes
- Pasta bowl builder
- Cart drawer, checkout form and order page with an order tracker
- Offers, locations (with location modal), about and contact pages
- API routes for contact, web push subscription and order push notifications
- Web push (web-push / OneSignal) and email (Resend / Mailgun / Nodemailer) integrations
- Postgres via @vercel/postgres / pg

## Tech stack

- **Framework:** Next.js, React, TypeScript
- **Styling/motion:** Tailwind (PostCSS), Framer Motion
- **Data:** Postgres (@vercel/postgres, pg)
- **Notifications:** web-push, OneSignal
- **Email:** Resend, Mailgun, Nodemailer
- **Hosting:** Vercel

## Getting started

```bash
npm install
npm run dev   # http://localhost:3000
```
